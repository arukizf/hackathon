# AI Smart Guide Astana
Проект для хакатона Build with AI (Трек: Smart City)

Интерактивный ИИ-гид на базе RAG-архитектуры, который предоставляет контекстные рекомендации по городу Астана.

  Демо и Презентация:
  
 Демо-видео: [https://youtu.be/XXZmeHP_NDQ?si=jgD6xji_0gL8mLC5]
 
 Презентация: Файл `presentation.pdf` в корне репозитория.

  Как работает система (RAG):
Система работает локально без выдуманных фактов (0% галлюцинаций). 
1. Сбор данных: Автоматизирован с помощью Python-скрипта `osm_scraper.py` (OpenStreetMap).
2. База знаний: Локальный файл `astana_poi.json`.
3. Генерация: Gemini API анализирует локацию пользователя, историю диалога и фильтрует JSON-базу, выдавая 1-3 релевантных места с четким планом действий.

 Тестовые сценарии
 
 Сценарий 1: Учет геолокации и фильтрация
 
   Вход: "Я на проспекте Туран. Где посмотреть хоккей?"
   Ожидаемый ответ: Выбор "Барыс Арены" (близко, профильно) с расчетом времени в пути и мотивацией.
   
 Сценарий 2: Память сессии (Контекстуальность)
 
   Вход: "А где перекусить после игры?" (без указания текущего места).
   Ожидаемый ответ: Рекомендации заведений (Mega Silk Way, Navat) именно в радиусе стадионов, а не по всему городу.

  Ограничения и обработка ошибок:
  
 Динамические данные: Система честно предупреждает пользователя проверять актуальное расписание матчей и графики работы заведений (указано в системном промпте).
 Приватность (Zero-Tracking): Гео-данные передаются только как текстовый аргумент в промпт и не сохраняются в базе данных сессий.
